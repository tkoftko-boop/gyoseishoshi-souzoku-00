# gyoseishoshi-souzoku-00

## Project
相続を扱う行政書士向けWebサイト改善サンプル

## Purpose
既存の行政書士サイトにありがちな「情報が探しにくい・更新が止まっている・問い合わせ導線が弱い」といった課題を改善するサンプルサイト。

## Target
柏・流山周辺で相続相談を検討している50〜70代。

## Concept
「相続の何から始めればいい？を分かりやすく」

- TOP
- 相続サポート
- 料金
- FAQ
- 事務所紹介
- コラム
